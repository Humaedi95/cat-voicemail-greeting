# Cat Voicemail Greeting

A one-line voicemail greeting as if recorded by Miso, a cat with zero regrets
about the mug he knocked off the table. Run `main.ts` and it writes the
greeting to `/output/entry.txt`.

> Hi, it's Miso. Your mug is on the floor. I'd do it again. Leave a message after the beep, and bring tuna.
